# Car / Aeroplane / Ship Image Classification

Небольшой учебный проект по многоклассовой классификации изображений с помощью **PyTorch** и **ResNet-18**.

Модель обучается различать три класса изображений:

- `car` — автомобили;
- `aeroplane` — самолёты;
- `Ship` — корабли.

ResNet-18 обучается **с нуля** (`weights=None`), без использования предобученных весов ImageNet.

## Структура проекта

```text
car_aero_boat/
├── train.py          # обучение модели
├── predict.py        # предсказание класса для нового изображения
├── load.py           # пример загрузки датасета самолётов через KaggleHub
├── aeroplane/        # изображения самолётов
├── car/              # изображения автомобилей
├── Ship/             # изображения кораблей
└── checkpoints/      # сохранённые веса модели после обучения
```

Папки `aeroplane/`, `car/` и `Ship/` должны содержать изображения соответствующих классов. Названия классов автоматически определяются через `torchvision.datasets.ImageFolder`.

## Модель

В проекте используется архитектура **ResNet-18**:

```python
model = models.resnet18(weights=None)
model.fc = nn.Linear(model.fc.in_features, num_classes)
```

Стандартный последний слой ResNet заменяется на линейный слой для трёх классов:

```text
изображение 3×224×224
        ↓
     ResNet-18
        ↓
  512 признаков
        ↓
  Linear(512, 3)
        ↓
car / aeroplane / Ship
```

Так как используется `weights=None`, все веса сети инициализируются случайно и обучаются непосредственно на подготовленном датасете.

## Подготовка изображений

Перед подачей в нейросеть изображения приводятся к размеру `224 × 224` и нормализуются.

Для обучающей выборки дополнительно используется случайное горизонтальное отражение:

```python
transforms.Resize((224, 224))
transforms.RandomHorizontalFlip()
transforms.ToTensor()
transforms.Normalize(
    mean=[0.485, 0.456, 0.406],
    std=[0.229, 0.224, 0.225],
)
```

Для validation случайная аугментация не применяется.

## Обучение

Основные параметры обучения:

| Параметр | Значение |
|---|---:|
| Архитектура | ResNet-18 |
| Размер изображения | 224 × 224 |
| Количество эпох | 10 |
| Batch size | 32 |
| Learning rate | `1e-4` |
| Optimizer | Adam |
| Loss | CrossEntropyLoss |
| Validation | 20% |
| Максимум изображений на класс | 1000 |
| Random seed | 42 |

Из каждого класса случайно выбирается не более 1000 изображений. После этого выбранные данные делятся на обучающую и валидационную выборки в отношении 80/20.

Если CUDA доступна, обучение выполняется на GPU. В противном случае используется CPU.

## Установка

Необходим Python 3 и библиотеки:

```bash
pip install torch torchvision pillow kagglehub
```

Для самого обучения `kagglehub` не требуется — он используется только в `load.py`.

## Запуск обучения

Сначала необходимо разместить изображения в папках классов:

```text
aeroplane/
car/
Ship/
```

Затем запустить:

```bash
python train.py
```

Во время обучения для каждой эпохи выводятся значения loss и accuracy на train и validation:

```text
Epoch 1/10 | train_loss=... train_acc=... | val_loss=... val_acc=...
```

После завершения обучения модель сохраняется в:

```text
checkpoints/car_boat_plane_local.pth
```

Checkpoint содержит:

- `model_state_dict` — обученные веса ResNet-18;
- `class_names` — список названий классов.

## Предсказание для нового изображения

В `predict.py` нужно указать путь к изображению:

```python
img_path = "test.png"
```

После этого запустить:

```bash
python predict.py
```

Скрипт загрузит сохранённую модель, обработает изображение и выведет предсказанный класс и вероятности для всех классов:

```text
Класс: car
Классы: ['Ship', 'aeroplane', 'car']
Вероятности: [...]
```

Вероятности вычисляются через `softmax`:

```python
probs = torch.softmax(logits, dim=1)
```

## Загрузка данных

В `load.py` находится пример загрузки датасета самолётов с Kaggle:

```python
import kagglehub

path = kagglehub.dataset_download("ciroanni/airplanes")
print("Path to dataset files:", path)
```

Этот скрипт только скачивает датасет и выводит путь к нему. Для обучения трёх классов изображения автомобилей, самолётов и кораблей должны быть подготовлены в отдельных папках самостоятельно.

## Как работает обучение

Для каждого batch выполняются стандартные этапы обучения нейросети:

1. изображения проходят через ResNet-18;
2. сеть выдаёт logits для трёх классов;
3. `CrossEntropyLoss` вычисляет ошибку;
4. `loss.backward()` вычисляет градиенты;
5. Adam обновляет веса модели;
6. считается accuracy.

На validation веса модели не изменяются — этот этап используется только для оценки качества классификации.

## Примечание

В текущей версии `train.py` использует папку, в которой находится сам скрипт, как корень `ImageFolder`. Поэтому `ImageFolder` рассматривает все подпапки рядом с `train.py` как потенциальные классы. После первого обучения там появляется папка `checkpoints/`, и при повторном запуске это может привести к ошибке, потому что в ней нет изображений.

Для более удобной структуры лучше хранить датасет отдельно, например:

```text
car_aero_boat/
├── train.py
├── predict.py
├── load.py
├── data/
│   ├── aeroplane/
│   ├── car/
│   └── Ship/
└── checkpoints/
```

и в `train.py` заменить:

```python
root_dir = Path(__file__).parent
```

на:

```python
root_dir = Path(__file__).parent / "data"
```
